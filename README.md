# 🧠 Brain Sticky (脑雾收集站)

> **极简第二大脑 Super App** · 专为对抗脑雾、日常琐事焦虑与冲动消费打造的纯本地离线个人助理。
> 
> A clean, aesthetic, and privacy-first Personal Second Brain & Micro-Habit App built with SwiftUI.

---

## ✨ Features / 核心功能

1. **待办 (Todo)**
   - 闪电录入、倒数定时提醒、紧急/日常/随缘三档优先级
2. **日常 (Drops)**
   - 随手捕捉灵感碎碎念与心情便签，支持 8 种柔彩底色与可爱表情
3. **密码箱 (Vault)**
   - 记录备忘口令与生活凭证，支持 Face ID / Touch ID 硬件级安全芯片守护与一键大字展示
4. **买菜清单 (Market / Grocery)**
   - 智能分区归类、进度环、自定义常购物品库一键加购
5. **剁手心愿 (Wishlist)**
   - 多币种（¥ CNY, $ USD, 円 JPY, € EUR）冷静期倒计时机制，告别冲动消费
6. **打卡微习惯 (Check-in & Habits)**
   - 自定义日常习惯模块、内置精美预设图标、主题色与进度统计
7. **全域深度检索 (Omni Search)**
   - 毫秒级即时检索全库所有待办、日常、密码、买菜、心愿与习惯
8. **双语支持 (Bilingual)**
   - 简体中文 / English 完整自适应国际化

---

## 🔒 Privacy & Architecture / 隐私与架构

- **100% 纯本地离线**：无任何中心化云端数据收集服务器
- **安全隔离**：敏感凭证由苹果安全芯片（Secure Enclave）与 Keychain 守护
- **架构**：纯 SwiftUI + Swift 5.0，原生流畅触感反馈

---

## 🛠️ Requirements & Build / 环境与构建
